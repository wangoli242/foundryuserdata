# Temporary Custom Statuses

A module that allows you to create and save custom status effects.

## Installation

You can install this module by pasting the following manifest link into Foundry VTT's "Install Module" dialog:

`https://github.com/Agraael/temporary-custom-statuses/releases/latest/download/module.json`
